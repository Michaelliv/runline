# runline

Runline is now [codemode](https://github.com/shift-labs-ai/codemode), published as [`@shiftlabs/codemode`](https://www.npmjs.com/package/@shiftlabs/codemode).

This package forwards to `@shiftlabs/codemode` under the runline names: the `runline` command, the `Runline` class, and the `Runline*` types. It stops being published in 0.48.0.

Install the new package and follow [Migrate from runline](https://github.com/shift-labs-ai/codemode/blob/main/docs/migrating-from-runline.md):

```bash
npm install -g @shiftlabs/codemode
```
